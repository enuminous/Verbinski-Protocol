# The objective-function problem

The repo uses an intentionally transparent toy objective:

`J = wS*survival + wA*agency + wC*cohesion + wT*truth - wD*dependency`

The default weights are visible in code.

This is the most important part of the exercise because a search system does not discover values by itself. It optimizes whatever has been encoded, measured, or proxied.

A system can therefore become more capable at searching futures while becoming more dangerous if its target is incomplete, gameable, or morally impoverished.

Questions that should remain explicit:

- Is survival enough if agency collapses?
- Is social cohesion desirable if produced by coercion?
- Can truth be reduced to one scalar?
- What harms are invisible to the objective?
- Who selects the weights?
- Who gets standing to veto an apparently high-scoring future?

The toy simulator exists to expose those questions, not answer them.
